A complete technical breakdown of languages, design systems, and the interactive cursor-tracking robot animation.

1. Technologies & Languages Used

  • HTML5 (HyperText Markup Language): Semantic markup for document structure, accessible navigation landmarks, and direct vector SVG embedding.
  • CSS3 (Cascading Style Sheets): Custom properties (variables), 3D perspective (`perspective: 1200px`), glassmorphism backdrop filters, CSS keyframe animations, and mobile-first responsive media queries.
  • JavaScript (Vanilla ES6+): Pointer tracking math, vector normalization, linear interpolation (Lerp) animation loop with `requestAnimationFrame`, asynchronous `fetch()` API, and DOM event listeners.
  • Vector SVG (Scalable Vector Graphics): Hand-crafted multi-layered robot illustration with radial gradients, drop-shadow glow filters (`feGaussianBlur`), and helmet visor `clipPath`.
  • Node.js Built-in HTTP Server (`server.js`): Lightweight zero-dependency static file server with auto port-conflict recovery.
  • FormSubmit Cloud API: Secure asynchronous message forwarder sending visitor messages directly to `aadithyasivasankar10@gmail.com`.
  • Font Awesome 6 & Google Fonts (Outfit): Vector iconography and modern typography.

2. Project File Structure & Roles

  • index.html: Contains semantic sections: Navigation bar, Hero visual with Cyber Robot SVG, About (Education & Internships), Technical Skills, Projects, and Contact Form.
  • style.css: Global styling tokens, 3D space perspective, robot floating keyframes, glassmorphism cards, and responsive rules for tablet and mobile.
  • script.js: Mobile navbar controller, scroll-spy navigation, real-time mouse/touch vector tracking, Lerp loop, periodic eye blinking, and FormSubmit AJAX handler.

3. How the Robot Cursor-Tracking Animation Works (Step-by-Step)

The interactive robot avatar in the hero section is implemented across three coordinated layers:

Step A: SVG Layering Architecture (index.html)

In index.html (lines 60–295), the robot is built from independent vector groups:

  • #char-head: Contains the entire head (outer purple hood, inner silver arch, cyan headphones with pulsing antenna LED, and dark visor). This group pivots in full 3D.
  • #char-visor-group: Dark helmet shield with specular glass reflection overlays.
  • #char-eyes-container (with clip-path="url(#visorClip)"): Ensures the eyes stay naturally constrained inside the helmet screen.
  • #char-eyes (#eye-left, #eye-right): Glowing dual cyan-white eyes with radial gradients and neon glow filters.

Step C: Mouse Vector Math & Normalization (script.js)

In script.js (lines 116–160), mouse coordinates are converted into relative angles and bounded target values:

JavaScript: Pointer Vector Calculation
function handlePointerMove(clientX, clientY) {
    const rect = characterContainer.getBoundingClientRect();
    
    // Find the center of the robot's head in viewport pixels
    const charCenterX = rect.left + rect.width * 0.49;
    const charCenterY = rect.top + rect.height * 0.33;

    // Vector distance between cursor and head center
    const deltaX = clientX - charCenterX;
    const deltaY = clientY - charCenterY;

    // Normalize between -1.0 and +1.0
    const normX = Math.max(-1, Math.min(1, deltaX / (window.innerWidth * 0.4)));
    const normY = Math.max(-1, Math.min(1, deltaY / (window.innerHeight * 0.4)));

    // Set target positions for Eyes and 3D Head rotation
    targetEyeX = normX * 24;      // Max 24px eye displacement
    targetEyeY = normY * 18;      // Max 18px eye displacement
    targetHeadRotY = normX * 18;  // Max 18deg Yaw (left-right tilt)
    targetHeadRotX = -normY * 14; // Max 14deg Pitch (up-down tilt)
}

Step D: Smooth Physics via Linear Interpolation (Lerp) (script.js)

Instead of snapping rigidly, script.js (lines 187–218) runs a 60 FPS requestAnimationFrame loop that smoothly glides towards targets:

JavaScript: 60 FPS Lerp Loop
function animateCharacter() {
    const lerpEye = 0.10;  // Eye responsiveness damping factor
    const lerpHead = 0.08; // Head weight damping factor

    // Linear Interpolation: current = current + (target - current) * factor
    currentEyeX += (targetEyeX - currentEyeX) * lerpEye;
    currentEyeY += (targetEyeY - currentEyeY) * lerpEye;

    currentHeadRotY += (targetHeadRotY - currentHeadRotY) * lerpHead;
    currentHeadRotX += (targetHeadRotX - currentHeadRotX) * lerpHead;

    // Apply calculated transforms to the SVG DOM elements
    charEyes.style.transform = `translate(${currentEyeX.toFixed(2)}px, ${currentEyeY.toFixed(2)}px)`;
    charHead.style.transform = `translate(${currentHeadTransX.toFixed(2)}px, ${currentHeadTransY.toFixed(2)}px) 
                                rotateY(${currentHeadRotY.toFixed(2)}deg) 
                                rotateX(${currentHeadRotX.toFixed(2)}deg)`;

    requestAnimationFrame(animateCharacter);
}

Step E: Blinking & Micro-Interactions

  • Random Blinking: A timer executes every 3–6.5 seconds, squashing scaleY of the eyes to 0.08 for 160ms.
  • Window Exit Decay: When cursor leaves the browser window (mouseleave), all targets decay smoothly to 0, centering the robot.
  • Click Celebration: Clicking the robot triggers a bounce keyframe animation (robotCheer) and an excited double-blink.
  • Touch Screen Support: Mobile and tablet users can drag their finger across the screen to direct the robot's gaze.
